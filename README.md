## Comment utiliser
1. Démarer les trois fichiers (serveur_MQTT.py, simulation_MQTT.py, interface.py)
2. Sur simulation_MQTT.py, choisissez 1 ou 2 pour simuler une course
3. Suivez les étapes affichées par la console afin de bien envoyer la requête
4. Sur l'interface graphique, appuyez sur "Refresh" (la table devrait se mettre à jour avec les données envoyées par MQTT à l'étape précendante)
